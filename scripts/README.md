## KDE App Volume Control
Developed by [Simon99de + AI](https://github.com/Simon99de)

Script: [App Volume Control](https://github.com/Simon99de/scripts/app_volume_control.sh)

Script File: [app_volume_control.sh](app_volume_control.sh)

### Functions
I created this script with AI so that you can, for example, adjust Firefox audio separately while the rest remains at the same volume. 

To connect the script to the keyboard, use the function in KDE settings --> keyboard --> shortcuts to add scripts.

The script has been tested on Bazzite OS 43 KDE (Linux).

Instructions for use can be found in the file.
